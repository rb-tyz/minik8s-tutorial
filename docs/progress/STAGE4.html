复验命令

普通用户自检：

python3 grader/verify-stages.py --output /tmp/minik8s-stages-check-new

按 VM 环境说明 准备并校验输入后：

python3 reference/tests/vm/run.py \
  --image "$LAB/base.qcow2" --sha512 "$IMAGE_SHA512" \
  --crictl "$LAB/crictl.tar.gz" --crictl-sha256 "$CRI_SHA256" \
  --staged-grader --output /tmp/minik8s-stages-vm-new

最终运行使用上述路径对应的本地输入，并配置 --apt-proxy http://10.0.2.2:7897。 各轮 inputs.json 保存输入校验值，payload-manifest.json 保存实际执行载荷的 SHA256。

调试记录与清理

失败轮次保留在同一证据目录。主要修复包括：runc 后台子进程继承 stderr 管道导致等待； 容器 exec 前读取隔离信息的竞态；CRI 包装器未沿用 sandbox 配置；滚动更新期间 Pod 消失引发状态写入 404；Binding 夹具缺少身份字段；省略的 exitCode=0 默认值；Endpoints 删除已完成但 Bash 函数继承失败退出码。修复后重新执行最终完整验收。

certified-vm 是冻结代码后的最终结果。最终 CRI sandbox/container 集合与网络命名空间 均为空。每轮创建记录、UUID、销毁结果独立保存；最终 VM 已停止并删除临时磁盘、seed 和 密钥，见 销毁结果（本地工程附件）。 宿主机仅进行普通构建、输入校验及 QEMU 用户态网络启动。所有特权实验均在核对 UUID 的 KVM 内进行。本阶段 13 轮实验共创建 26 台临时 VM，均已停止销毁；任务下载缓存与临时二进制已删除。 已有十台 libvirt VM 保持关闭状态。最终汇总与清理统计见 acceptance.json（本地工程附件） 和 host-cleanup.json（本地工程附件）。
