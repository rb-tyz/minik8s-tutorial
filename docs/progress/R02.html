R02：Deployment 与 Endpoints 已通过真实容器验收

范围：原文 §13.4–13.5、DEPLOY-002、EPS-001/002；遵循 docs/MVP-SCOPE.md。 本轮由主 agent 执行，未调用 subagent。

已实现基础 RollingUpdate、template hash/owner UID、按申请量与就绪预算扩缩 RS， 以及 Service/Pod 事件驱动的 Endpoints、命名端口解析、无变化抑制与删除清理。 未加入暂停、回滚、进度期限、EndpointSlice 或 HA。

教学章节：08-deployment-endpoints.md。 接口契约：deployment-endpoints.md。 教学独立复现待验收；参考实现已通过 HTTP 和真实容器检查。

原文补充订正

  • §13.4 把 UpdatedReplicas 赋成新 RS ReadyReplicas，混合了新版本数量与就绪数量。 实验输入为新 RS replicas=1、ready=0：Updated=1，Ready 仍由旧版提供。 依据：固定版本 apps/v1 DeploymentStatus；TestRolloutWaitsForReadyAndMaintainsBudgets。
  • maxSurge=0 时，原文先等新版本 Ready 的门槛会阻止第一步；在 maxUnavailable 允许时， 先减少旧版，再增加新版即可取得进展。TestRolloutZeroSurgeUsesUnavailableBudget 验证。
  • 旧版未就绪副本不占用就绪预算，可回收以给新版腾出容量；已有就绪副本继续按预算保护。
  • 原文 computeMax* 未展开。本 MVP 公布整数/百分比取整及 422 约束，见教程。 Kubernetes 的百分比归零回退策略与本 MVP 的拒绝策略分别说明。

固定版本依据保存在 evidence/r02-20261106/sources/，来源为 https://github.com/kubernetes/api/blob/v0.29.0/apps/v1/types.go 和 https://github.com/kubernetes/kubernetes/blob/v1.29.0/pkg/controller/deployment/util/deployment_util.go 。 第一阶段审计文件与发布包保持原样，以上为实践阶段新增订正。

验证

  • controller/API 相关竞态测试通过；十轮重复竞态测试通过。
  • R01 测试客户端曾在并发 status 写入期间遇到正常 409。缩容测试改为重新 GET 后重试， 与公开 CAS 契约一致；没有跳过测试。失败记录见本次工具执行记录。
  • 从全新 KVM 构建并执行四进程验收，N01/R01/R02 共 25 项断言全部通过。
  • R02 真实结果：两个 v1 Running；EndPoints 将命名端口解析为 8080；更新为 v2 后， 记录中 RS 申请数最多 3、就绪数最低 2；新容器 CRI 环境变量为 v2，Pod UID 全部替换； Endpoints 引用新版 UID；删除 Service 后 Endpoints 404；删除 Deployment 后 RS/Pod 为零。
  • guest 容器/sandbox 已全部清理，两台临时 KVM 停止，overlay、seed 和 SSH key 目录删除。

日志：fresh-vm/acceptance.log（本地工程附件）。 断言：guest/summary.json（本地工程附件）。 滚动轨迹：rollout-trace.json（本地工程附件）。 销毁记录：vm-delete.json（本地工程附件）。
