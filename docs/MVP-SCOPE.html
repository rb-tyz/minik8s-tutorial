教学 MVP 的范围与验收

按用户本轮要求补充。交付目标是让具备 Go、Linux 和 HTTP 基础、对 Kubernetes 架构了解不深的学习者，通过修订教程独立实现可运行的 MiniK8s MVP。

教学深度

原文 audit/evidence/research/source-tutorial.md 第 11 行将读者设为已读前 38 章的资深工程师， 并默认其了解 Informer、namespace、PLEG 和调度绑定。修订版应在相应模块内解释这些前置概念， 给出数据流、接口、算法和可运行的小实验，避免要求读者先掌握 Kubernetes 的完整架构。 新增解释用于补足原文既有机制，功能与理论深度沿用原文及已确认的订正。

原文范围对齐的修改及实际结果另见 docs/progress/ALIGNMENT.md。 修订教程为 原文订正版，第三阶段交付见 STAGE3，docs/contracts/ 提供公开行为与对象细节，audit/ 保留审计 与订正记录。教程按下面的范围组织；参考实现的运行结果与教程对实现的覆盖情况分别记录。

MVP 主线

学习模块 原文与订正依据 学习者应能实现的行为
单机 KV 与 API §8–9；KV、API 类审计记录 revision、单键 CAS、前缀 List、对象 CRUD；补足项目要求的简单持久化与重启恢复
Watch §10；KV-001、KV-004、WATCH 类记录 List 后从 RV 续接、保留窗口、410 后重新同步、按已交付顺序发送 bookmark
Informer/Queue §13.1–13.2；INFORMER、QUEUE 类记录 本地缓存、变更通知、按 key 去重、失败重试和退出
Scheduler §12；SCHED 类记录 从已绑定 Pod 计算用量，筛选节点，条件绑定，删除后释放资源
Kubelet/Runtime §6–7、§11；RUNTIME、KUBELET 类记录 sandbox 与容器的区别，启动/查询/清理，init 顺序，重启策略和 status
ReplicaSet §13.3、§13.6；RS 类记录 owner UID、template 生成 Pod、维护副本、更新状态、父对象删除后的简单清理
Deployment §13.4；DEPLOY-002，保留 DEPLOY-001 订正后的正常等待行为 template 变化创建新 RS，按 maxSurge/maxUnavailable 步进并等待就绪
Endpoints §13.5；EPS-001/002 selector 选 Pod，按就绪和端口生成后端，Pod 变化触发重算，Service 删除后清理
Pod 网络与 Service §14–15；CNI、PROXY 类记录 IPv4 bridge/IPAM、同节点通信、按 §14.4 手工静态路由跨节点、ClusterIP 与清理

MVP 完成演示包含 Pod 创建/调度/运行/查询、RS 删除恢复、基础 Deployment 更新、Pod 网络 与 Service 通信，以及原文的双节点静态路由实验。单节点演示与双节点验收分别保存结果。N01 的早期运行时实验使用 host 网络；P01 已实现独立 Pod 网络与 Service， I01 组合 Deployment 与 Service 验证实际请求。最新结果见 原文范围对齐。

原文 §3.1、§14.4 的静态路由跨节点通信纳入本轮；NodePort、DNS、路径路由放在后续扩展。HPA、指标监控、Service Mesh、Serverless、 HA/Raft、leader election、EndpointSlice，以及 Deployment 暂停、历史回滚、进度期限等 能力均不加入本轮教学主线。已有类型中预留的字段也不自动构成 MVP 要求。

现有实现与教学主线的对照

以下是实现与教材的对应原则。正文按原文顺序订正，具体修改见 订正记录；原有模块稿和覆盖索引保留供回溯。

已有实现选择 教学处理
KV 二进制日志、header/payload CRC、故障注入 主线讲简单追加、确认写入、重启恢复；私有编码与校验细节放实现附录，黑盒验收接受其他满足公开语义的持久化方案
Scheduler 单 worker、每次 List 建账 用它解释资源计算与原子绑定，并说明对原文 Assume 账本的简化；学习者无需重现生产调度缓存
RS 计数条件 已按原文 §13.3 补齐 owner + selector 的计数与状态测试，第 07 章解释匹配、归属与活跃副本
RS 稳定 slot 名称与每轮 List 讲清重试时避免重复创建的原因及一种简单方案；slot 命名规则是参考实现选择
containerd + crictl 适配 项目允许复用成熟运行时；教程提供安装、配置、命令和状态映射，学习者实现窄适配接口。手工 namespace/cgroup/runc 放在原理实验中
Kubelet 周期查询与串行协调 描述当前观察与收敛过程，同时解释原文 PLEG/pod worker 的职责及这里的简化
VM UUID guard、超时、清理工具 作为提供给学习者的实验设施，沿用项目隔离要求
响应丢失、同名重建等恢复测试 各章公布重读、UID/RV、接管与重试步骤；测试器按已公布的行为和条件验收

实现中发现的问题先追溯原文或审计记录。属于订正所必需的，补充到对应章节及验收说明； 属于参考实现的工具选择或强化措施的，写入实现说明；范围外的新功能留待扩展。

实验与教程覆盖验收

按用户最新要求，交付验收检查两件事：实验正确、实现能被教程覆盖。

  1. 实验提供输入、环境、命令、断言、日志及清理记录；容器和网络结论来自获批 KVM 的实际运行。
  2. 每项必过行为都能在教程或随章链接的公开契约中找到输入输出、数据结构、算法步骤、 并发/失败处理、开发建议和复现方法。实现选择与教学必需机制分别说明。
  3. 对实现中发现的错误，同步补充原因、修复与验证方法；新的公开行为同步更新教程和测试器。
  4. 学习者反馈用于后续改进。当前交付以实验结果和教材覆盖检查为依据。

逐章对应关系见 实验与教程覆盖检查。
