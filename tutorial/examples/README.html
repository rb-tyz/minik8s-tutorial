课程示例对象

四份 JSON 均由真实 API 校验。pod/replicaset/deployment 分别演示三个创建层级； Service 选择 Deployment 的 app=course-web，端口 80 对应 Pod 的命名端口 web=8080。 它们采用不同 app 标签，便于在同一 namespace 中观察归属。

metadata.namespace 留给请求 URL 或 CLI --namespace。resources.cpu=50 为毫核， memory=67108864 为字节。示例镜像由 VM 环境构建并导入，它的 HTTP 响应为 POD_MARK； 准备过程见 集成章。这些 JSON 是 MiniK8s 公共格式，真实 Kubernetes 的 resources/strategy 等字段格式有差异。

API 练习只启动 API；实际工作负载练习在已批准的 VM 中运行，见 workloads。
