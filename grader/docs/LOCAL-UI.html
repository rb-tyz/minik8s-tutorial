本地课程界面

安装命令后，在学习者项目目录运行：

minik8s serve

浏览器访问 http://127.0.0.1:7331。指定项目或端口：

minik8s --project /path/to/my-minik8s serve --port 7331

服务使用 Python 标准库；页面的 HTML、CSS、JavaScript 随测试器分发，运行时无需下载前端依赖。 停止服务使用 Ctrl+C，服务会请求正在运行的提交停止，并等待测试器清理。

页面操作

左侧按十个小节分组，展开后选择小 stage。每关先说明你要实现的行为，再给测试输入、通过条件和实现提示。页尾可打开本节的接入说明和对应的前置关卡；安装、进度与排错在公共指南中。教程等外部资料在新标签页打开。 配置按钮设置 adapter、driver、调用协议、API 地址、CNI 和 fixture，配置保存在当前项目。正常提交不需要填写 VM UUID；minik8s submit 会为每个 stage 自动创建一次性 KVM。

“提交本阶段”验收当前进度，通过后保存下一阶段。浏览其他阶段时，按钮变为“练习本阶段”， 该模式保留课程进度。“全量测试”从第一阶段开始，遇首个失败停止。 测试结果显示逐项状态、失败原因与运行日志；取消后等待清理完成，再允许发起下一次提交。

页面与终端共用 .minik8s/。在另一个终端提交后，页面会刷新进度。服务重启后读取已有进度 与最近结果。一个服务对应一个学习者项目。

实验环境

每次 submit 都会从 ~/.cache/minik8s/vm/base.qcow2 启动一个一次性 guest，并用同目录 base.sha512 校验。 1.1 起的普通用户态检查在 guest 内运行，容器、cgroup 和网络阶段使用同一 guest 的能力； 宿主机不执行特权实验。低层 test.sh 仍可在已提供的 guest 内运行并核对 VM 身份。

课程服务可以运行在学习环境或该 guest 中。用 SSH 转发同一端口后，在本机浏览器访问：

ssh -N -L 7331:127.0.0.1:7331 user@lab-vm

第一小节的文件准备和 VM 内提交见 首次提交。

本地 HTTP 接口

方法与路径 行为
GET /api/course 十个小节、170 个 stage 正文、项目路径、配置及本次服务的提交令牌
GET /api/material?path=grader/docs/ADAPTER.md 读取一份公开文档，返回 path 和 markdown
GET /materials/grader/docs/ADAPTER.md 在课程页面中打开文档，支持段落锚点
GET /api/state 当前进度、最近结果、活动任务 ID、提交历史 ID
GET /api/jobs/ID 本次服务内任务的状态、事件、诊断日志和结果
GET /api/runs/RUN_ID 已保存的 CLI 提交结果
POST /api/config 更新配置字段，空字符串移除该字段
POST /api/submissions {} 提交当前阶段，{"stage":"3.4"} 临时练习，{"all":true} 全量测试
POST /api/jobs/ID/cancel 请求取消，等待 CLI 清理

写请求携带 X-Minik8s-Token。服务固定监听 127.0.0.1，核对 Host、Origin 与令牌， 静态文件使用固定映射。提交参数转为 CLI 参数数组，CLI 负责版本化进度、项目锁和测试执行。 每个服务同时运行一个提交；来自另一个终端的项目锁也会被遵守。

任务状态为 running、cancelling、cancelled、passed、failed。前端轮询任务状态与事件， 持久结果沿用 CLI 协议。

验证

python3 -m unittest discover -s grader/tests -v
python3 grader/verify-teaching.py
mkdir -p /tmp/minik8s-reader-check
python3 grader/verify-single-page.py --output /tmp/minik8s-reader-check

浏览器检查自动启动临时课程服务，需要 Python Playwright 和本机 Google Chrome。它检查全部阶段的单页说明、页内提示、一次 KV 提交及桌面/窄屏布局，并保存截图；测试使用临时工程。

单页任务与新调用接口的验收：

python3 grader/verify-single-page.py --output /tmp/minik8s-single-page-check
python3 -m unittest discover -s grader/tests -v

浏览器验收使用 Python Playwright 和系统 Chrome，临时启动本地课程服务，逐一检查 170 页并运行一次普通用户态 KV 提交。
