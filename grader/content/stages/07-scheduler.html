7. Scheduler：筛选、资源、评分与绑定

用测试创建的 Node 对象验证 节点筛选、已绑定 Pod 的资源占用、应用和 init 容器的资源请求、饥饿、释放与评分；不启动真实容器，不要求特定 Informer 实现。

本节接入

本节运行 apiserver 和你的 scheduler。测试器通过 API 创建 Node 对象和 Pod，预设 Node 的 Ready、allocatable 等字段；需要预占用资源时，再创建已绑定的 Pod。scheduler 选择节点并通过绑定接口写回结果。

测试器 GET Pod，读取 spec.nodeName 判断它被绑定到哪里。例子里的 good、small 等是节点的简称，实际名字带有本轮前缀。CPU 请求单位为毫核，内存请求单位为字节。结束后测试器按自己记录的名字删除 Node。
