8. Controllers：RS、Deployment 与 Endpoints

通过公开 API 和 /status 观察值验收 ReplicaSet、Deployment 与 Endpoints。每关只新增一种控制器行为，不读取控制器私有状态。

本节接入

本节运行 apiserver 和 controller-manager。测试器通过 API 创建或更新资源，在需要模拟就绪的关卡中调用 Pod 的 /status。控制器从 API 读取对象、更新期望副本和状态；测试器再从 API 观察结果。

ReplicaSet（RS）按 ownerReferences 中的 UID 和 selector 识别子 Pod。Deployment 创建或调整 RS，由 RS 管理 Pod。Endpoints 控制器根据 Service 的 selector、Pod IP、端口和就绪状态生成同名 Endpoints。这里检查的是这些对象；实际网络流量在第 10 节验收。
