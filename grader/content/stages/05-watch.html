5. HTTP Watch：快照、重放、事件与游标

通过长连接读取 NDJSON，分别验收初始快照、空快照、顺序、bookmark、重放、实时新增/修改/删除、namespace 过滤与游标。

本节接入

沿用第 4 节的 apiserver 和启动脚本。测试器打开 GET /api/v1/namespaces/NS/pods?watch=true 后保持连接，同时用其他 HTTP 请求创建、修改或删除 Pod。apiserver 在原连接每行发送一个 JSON 事件并及时刷新；普通 List 则一次返回一个 JSON 对象。

区分三种起点：省略 resourceVersion 时发送初始快照和 BOOKMARK；给出 List 版本时从其后续事件读起；显式给 0 时重放保留的历史。测试器结束后关闭连接并清理它创建的 Pod。
