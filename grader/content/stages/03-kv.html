3. KV：版本、CAS、快照、Watch 与恢复

把键值操作拆成读取、覆盖、前缀、版本、条件写入、删除、订阅历史与压缩、重启恢复。每个断言只要求本关公开的字段。

本节接入

测试器执行 ./bin/my-minik8s kv --listen HOST:PORT --state-dir DIR，随后把每个操作作为单独的 HTTP POST 请求发到 /call。同一轮使用同一个服务进程。正常业务响应使用 HTTP 200，JSON 的 ok 字段表示操作结果；键不存在等错误带 code。

entry.revision 表示这个键最后一次修改时的版本；list 的 revision 表示整份快照的版本。watch 注册带名字的订阅，next 请求读取该订阅的一次结果。关卡例子给出的数字版本用于说明请求顺序；客户端实际使用上一次响应中的版本。测试结束由测试器停止服务，3.22 还会强杀后用同一个目录重新启动。
