1.6 启动后台任务并返回身份 KVM PROCESS-BACKGROUND
1.7 结束后台任务并允许重复 reset KVM PROCESS-RESET
1.8 切换根目录与挂载视图 KVM CONTAINER-ROOTFS
1.9 让 fixture 成为容器内的 PID 1 KVM CONTAINER-PIDNS
1.10 隔离 network namespace KVM CONTAINER-NETNS
1.11 隔离 UTS namespace KVM CONTAINER-UTSNS

1.13 应用 CPU 毫核配额 KVM CONTAINER-CPU

1.17 限制 capability 集合 KVM CONTAINER-CAPS
