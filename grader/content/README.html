MiniK8s 课程目录

课程分为十个小节、70 个 stage。每次普通 submit 只验收当前一项能力。

编号使用“小节.阶段”，例如 minik8s stage 3.1。小节原理通过 minik8s section 3 阅读。

1. 手工运行容器

小节说明

Stage 任务 检查
1.1 启动任务并取得退出码 CONTAINER-EXIT
1.2 设置根目录与 PID 空间 CONTAINER-PIDROOT
1.3 隔离网络与主机名视图 CONTAINER-NAMESPACES
1.4 限制 CPU、内存与进程数 CONTAINER-CGROUP
1.5 收紧系统调用与权限 CONTAINER-SECURITY

2. CRI 边界

小节说明

Stage 任务 检查
2.1 创建 Pod sandbox CRI-SANDBOX
2.2 创建但暂不启动容器 CRI-CREATE
2.3 启动容器并列举任务 CRI-START
2.4 保留结束任务的状态 CRI-EXIT
2.5 拉取并运行缺失的镜像 CRI-PULL
2.6 删除容器与 sandbox CRI-LIFECYCLE

3. KV

小节说明

Stage 任务 检查
3.1 写入和读取一个键 KV-GET
3.2 按前缀列举键 KV-LIST
3.3 给提交分配版本 KV-REVISION
3.4 拒绝旧版本覆盖 KV-CAS
3.5 删除键并返回旧值 KV-DELETE
3.6 补发快照后的事件 KV-REPLAY
3.7 推送删除事件并取消订阅 KV-WATCH
3.8 处理过旧的订阅位置 KV-COMPACT
3.9 在进程崩溃后恢复 KV-RECOVERY

4. API

小节说明

Stage 任务 检查
4.1 创建并查询 Pod API-CREATE
4.2 列举 namespace 内的对象 API-LIST
4.3 按版本替换对象 API-REPLACE
4.4 删除与同名重建 API-DELETE
4.5 合并局部更新 API-PATCH
4.6 单独更新观察状态 API-STATUS
4.7 拒绝无效输入 API-VALIDATION
4.8 把 Pod 绑定到 Node API-BINDING
4.9 重启后保留对象身份 API-RESTART

5. Watch

小节说明

Stage 任务 检查
5.1 发送初始对象快照 WATCH-SNAPSHOT
5.2 标记初始同步结束 WATCH-BOOKMARK
5.3 接续 List 与 Watch WATCH-REPLAY
5.4 发送完整删除事件 WATCH-INITIAL
5.5 拒绝非法游标 WATCH-INVALID

6. Kubelet

小节说明

Stage 任务 检查
6.1 运行已绑定的 Pod NODE-RUN
6.2 传递资源与安全配置 NODE-RESOURCES
6.3 上报退出码与终态 NODE-EXIT
6.4 等待 init 容器完成 NODE-INIT
6.5 向容器传入环境变量 NODE-ENV
6.6 在 init 与应用间共享目录 NODE-SHARED
6.7 执行只读卷约束 NODE-READONLY
6.8 按 OnFailure 策略重试 NODE-RETRY
6.9 恢复镜像拉取失败 NODE-PULL
6.10 重启后接管现有容器 NODE-RESTART
6.11 度过 API 短暂中断 NODE-API-OUTAGE

7. Scheduler

小节说明

Stage 任务 检查
7.1 筛选可用节点 SCHED-FILTER
7.2 计算已绑定请求的占用 SCHED-CAPACITY
7.3 计入 init 资源需求 SCHED-INIT
7.4 按使用比例评分 SCHED-SCORE

8. Controllers

小节说明

Stage 任务 检查

8.2 补回被删除的副本 CTRL-REPLACE

8.8 清理 Service 的自动后端 CTRL-ENDPOINTS
8.9 在重启后继续调谐 CTRL-RESTART

9. CNI

小节说明

Stage 任务 检查

9.3 检查实际网络配置 CNI-CHECK
9.4 重复删除已经消失的网络 CNI-DEL

小节说明
