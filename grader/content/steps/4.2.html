Stage 4.2：读取不存在的对象

测试器按名字 GET 一个不存在的 Pod。让 apiserver 返回 HTTP 404，并在响应体给出 Status 错误对象。

测试方式

HTTP 404；响应是错误对象。

GET /api/v1/namespaces/NS/pods/absent
HTTP 404  {"kind":"Status","code":404,"reason":"NotFound"}

实现思路

把存储键未找到映射为 HTTP 错误，不返回 200 空 JSON。
