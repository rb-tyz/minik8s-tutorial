Stage 2.4：同一 sandbox 内创建两个容器

让同一个 sandbox 下的两次 container-create 建立两个独立的容器。测试器比较你两次返回的容器 ID。

测试方式

两次创建都成功，返回两个非空且不同的 ID。2.3 已验收创建后的状态。

./bin/my-minik8s sandbox-run --state-dir work
# 将返回的 id 记为 $sid
./bin/my-minik8s container-create --state-dir work --sandbox "$sid" --arg=pause   # 取得第一个 ID
./bin/my-minik8s container-create --state-dir work --sandbox "$sid" --arg=pause   # 取得第二个 ID

实现思路

使用运行时返回的真实 ID，不要按固定字符串生成而忽略冲突。
