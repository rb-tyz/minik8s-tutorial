Stage 1.3：返回任意真实退出码

让 my-minik8s 报告 fixture 的真实退出码。即使 fixture 退出 42，只要等到了结果，my-minik8s 自己也应退出 0，并把 42 放进 JSON 的 exitCode。

测试方式

两次调用的 exitCode 分别为 42 和 7，调用命令本身都退出 0。

./bin/my-minik8s container-run --state-dir work --rootfs lab/rootfs \
  --cgroup-parent "$parent" --nonce run-a --wait true --arg=exit --arg=42
# my-minik8s stdout: {"ok":true,"exitCode":42}
./bin/my-minik8s container-run --state-dir work --rootfs lab/rootfs \
  --cgroup-parent "$parent" --nonce run-a --wait true --arg=exit --arg=7
# my-minik8s stdout: {"ok":true,"exitCode":7}

实现思路

Go 的 cmd.Wait() 遇到非零退出码会返回 *exec.ExitError，可以从中读到 fixture 的退出码。启动 fixture 本身失败是下一关的情况。
