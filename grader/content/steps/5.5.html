Stage 5.5：拒绝非法游标

你的任务

在开始长连接响应之前校验 resourceVersion。

程序怎样被调用

本阶段继续运行 API 服务。测试器用 HTTP 建立 Watch 长连接，再从另一个连接创建或删除对象。 Watch 表示持续订阅对象变化；返回格式是 NDJSON，即每行一个 JSON 事件。

本页 URL 使用 demo 作为 namespace 示例。一个事件中的 type 表示变化类型，object 是对应 对象。resourceVersion 是对象或快照的存储版本，用于说明从哪里接收后续变化。 API 的启动和停止仍使用 --adapter 指定的脚本目录。

在发出流头之前校验

测试器请求一个非法版本：

GET /api/v1/namespaces/demo/pods?watch=true&resourceVersion=bad

预期是 HTTP 422。调用方据此知道请求参数有问题，能够修正后重新发起。 resourceVersion 的正常格式是十进制非负整数字符串；正版本用于续接该位置之后的事件。

实现思路

先解析查询参数并验证，再写 HTTP 200 和事件流。历史位置已过期的处理沿用 KV 的窗口规则， 完整 HTTP 约定见公开 API 文档。

本小节的原理与接口说明

测试方式

WATCH-INVALID：resourceVersion=bad 立即返回 422。

本阶段使用 普通用户 环境，只执行这一项检查。测试会准备本次输入，并在结束后回收本次资源。

提交代码

minik8s submit
