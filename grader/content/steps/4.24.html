Stage 4.24：重启 API 保留对象身份

让 apiserver 用同一数据目录重启后还能读到已保存的 Pod。测试器创建 Pod，再调用你的 restart apiserver 脚本，核对 UID 和版本。

测试方式

重启后同一 UID 与版本可读。

POST /api/v1/namespaces/NS/pods → 201，记录 Pod restart 的 UID 与版本
./test-hooks/restart apiserver "$WORKDIR"
GET /api/v1/namespaces/NS/pods/restart → 200，UID 与版本均保留

实现思路

API 打开同一 KV 数据目录并恢复对象；不要重新分配 UID。
