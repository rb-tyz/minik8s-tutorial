Stage 2.2：删除 sandbox

实现 sandbox-remove，删除测试器按返回 ID 指定的 sandbox。随后查询这个 ID 时，你的程序要返回业务错误。

测试方式

删除返回 ok=true；后续 status 为非成功的业务错误，而不是伪造 READY。

./bin/my-minik8s sandbox-run --state-dir work
# 将返回的 id 记为 $sid
./bin/my-minik8s sandbox-remove --state-dir work --id "$sid"
./bin/my-minik8s sandbox-status --state-dir work --id "$sid"
# 最后一次查询返回 ok:false

实现思路

删除后同步更新自己的记录；不要仍返回缓存的旧状态。
