Stage 9.2：veth 与网桥连接

插件处理 ADD 时，将 veth 的一端放进指定 netns 并启用为 eth0，把另一端接到配置指定的网桥。测试器在 KVM 内用 ip 查看两端。

测试方式

目标 netns 的 eth0 带 UP 标志，本轮 bridge 下有已接入的成员接口。

ip -n <netns> -j link show dev eth0 → flags 含 UP
ip -j link show master <本轮 bridge> → 至少有一个成员接口

实现思路

按容器 ID 生成稳定的 host 接口名；把 peer 放入目标 netns。
