Stage 4.11：Merge PATCH 递归合并对象

为 apiserver 实现 JSON Merge Patch 的对象合并。测试器新增一个标签，原有的标签应当保留。

测试方式

响应同时包含原有的 labels.app 和新增的 labels.version。

PATCH /api/v1/namespaces/NS/pods/patch-merge   # application/merge-patch+json
{"metadata":{"resourceVersion":"2","labels":{"version":"v2"}}}
# 版本取自创建响应，此处以 "2" 为例

实现思路

按 RFC 7396 递归合并对象；先合并再校验/CAS。
