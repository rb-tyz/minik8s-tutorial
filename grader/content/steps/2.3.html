Stage 2.3：创建但不启动容器

实现 container-create，在给定 sandbox 中创建应用容器并返回容器 ID。测试器紧接着查询状态，此时应用还没有启动。

测试方式

状态为 CONTAINER_CREATED，ID 来自真实运行时。

./bin/my-minik8s sandbox-run --state-dir work
# 将返回的 id 记为 $sid
./bin/my-minik8s container-create --state-dir work --sandbox "$sid" --arg=pause
# 将返回的 id 记为 $cid
./bin/my-minik8s container-status --state-dir work --id "$cid"
# stdout: {"ok":true,"state":"CONTAINER_CREATED"}

实现思路

区分 create 与 start。保存应用容器 ID 与所属 sandbox 的关联。
