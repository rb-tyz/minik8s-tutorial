Stage 9.5：重复 ADD 返回原地址

让重复 ADD 幂等。测试器给同一个容器 ID、同一个 netns 再发一次 ADD，你的插件要返回第一次分配的地址。

测试方式

对同一身份再次 ADD，返回的地址仍是 10.249.8.2/29。

ADD pod-a -> .2
再次 ADD pod-a -> .2

实现思路

先查容器 ID 是否已有记录，再分配；重复 ADD 应重建/检查接口。
