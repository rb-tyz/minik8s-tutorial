Stage 1.13：应用 CPU 毫核配额

根据 --cpu 50 给后台任务设置 50 毫核的 CPU 配额。你的运行时在 --cgroup-parent 下建立任务组，将任务放进去。测试器按返回的 PID 找到它实际所属的 cgroup，再读 cpu.max。

测试方式

cpu.max 为 5000 100000。

./bin/my-minik8s container-run --state-dir work --rootfs lab/rootfs \
  --cgroup-parent "$parent" --nonce run-iso --cpu 50 --memory 67108864 --pids 512 \
  --wait false --arg=pause --arg=run-iso-1
# /sys/fs/cgroup/<group>/cpu.max -> 5000 100000

实现思路

50 毫核对应每 100000 微秒可运行 5000 微秒。读 /proc/<pid>/cgroup 可得到任务实际所在的组，向该子组的 cpu.max 写入两个以空格分隔的十进制数。父组由测试器回收。
