Stage 6.5：运行一个已绑定 Pod

测试器提交一个已绑定到本节点的 Pod。让 kubelet 通过 CRI 启动应用容器，并把真实容器 ID 写回 Pod 状态，供测试器独立查询。

测试方式

Pod Running；独立 CRI inspect 显示同一 container ID 为 RUNNING。

从 GET /api/v1/nodes 选出首个 Ready 节点，记下 metadata.name
创建 Pod run，将 spec.nodeName 设为该节点名
GET Pod → Running，从 containerStatuses[0] 取出 containerID
crictl inspect 该 ID → CONTAINER_RUNNING

实现思路

保存 Pod UID、sandbox ID、容器 ID 的关联；创建后查询实际运行时状态。
