Stage 2.13：拉取并运行缺失镜像

实现 image-pull。测试器先确认本轮新 tag 没有缓存，再让你的程序拉取镜像、查询镜像 ID，并用它创建容器读取镜像内的 /pull-proof。

测试方式

拉取前 image-status 返回 ok:false，拉取后返回非空镜像 ID。容器能从该镜像读取 /pull-proof，最终状态为 CONTAINER_EXITED，退出码为 0。

# $image 是测试器为本轮生成的新 tag，$sid 是本轮 sandbox ID
./bin/my-minik8s image-status --state-dir work --image "$image"
./bin/my-minik8s image-pull --state-dir work --image "$image"
./bin/my-minik8s image-status --state-dir work --image "$image"
./bin/my-minik8s container-create --state-dir work --sandbox "$sid" --image "$image" --arg=read --arg=/pull-proof
# 用创建响应中的 id 启动容器，再查询其终态

实现思路

镜像仓库为本轮分配一个新 tag。镜像层可以复用；测试器最终用该 tag 创建容器，让 fixture 读取镜像内的 /pull-proof。
