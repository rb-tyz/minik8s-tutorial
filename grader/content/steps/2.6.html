Stage 2.6：启动一个，另一个保持 Created

一个 sandbox 有两个已创建的容器时，只启动 container-start --id 指定的那个。测试器分别查询两个容器。

测试方式

first 为 RUNNING，second 仍为 CREATED。

# $first、$second 是刚在同一 sandbox 创建的容器 ID
./bin/my-minik8s container-start --state-dir work --id "$first"
./bin/my-minik8s container-status --state-dir work --id "$first"
./bin/my-minik8s container-status --state-dir work --id "$second"

实现思路

不要用 sandbox 级状态覆盖单个容器状态；状态查询按容器 ID。
