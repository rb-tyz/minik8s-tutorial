Stage 1.7：结束后台任务并允许重复 reset

为 my-minik8s 增加 reset。测试器先启动后台 fixture，再用同一个 --state-dir 调用 reset。你的程序要找到并结束这个任务，等它消失后返回成功；再次 reset 也应成功。

测试方式

第一次 reset 后 PID 不再存在；第二次 reset 返回 ok=true。

./bin/my-minik8s container-run --state-dir work --rootfs lab/rootfs \
  --cgroup-parent "$parent" --nonce run-a --wait false --arg=pause
# 保存响应中的 pid，供检查使用
./bin/my-minik8s reset --state-dir work
./bin/my-minik8s reset --state-dir work
# 两次 reset 的 stdout 都是 {"ok":true}

实现思路

把 PID/身份写入 state-dir；发送可处理的终止信号并等待，避免留下僵尸或复用错 PID。
