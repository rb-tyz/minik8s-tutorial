Stage 4.1：创建并读取 Pod

让你的 apiserver 接受创建 Pod 的 HTTP 请求，分配 UID 和 resourceVersion，再允许测试器按名字读回它。从这一节起，测试器通过你提供的 test-hooks/start、stop、restart 脚本管理服务。

测试方式

POST 返回 201 与身份；GET 返回同一 UID/RV 和 spec。

POST /api/v1/namespaces/NS/pods
{"metadata":{"name":"demo"},"spec":{"containers":[{"name":"app","image":"minik8s.local/fixture:n01","command":["/fixture"],"args":["pause"]}]}}
→ HTTP 201，记下 metadata.uid 和 metadata.resourceVersion
GET /api/v1/namespaces/NS/pods/demo → HTTP 200，返回同一个 Pod

实现思路

解析集合与对象路径，写 KV，读回时投影 resourceVersion。UID 由服务端生成。
